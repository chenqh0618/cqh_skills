# 按请求审核分析结论

用户要求正式审核时，判断结论是否得到实际数据支持，以及适用范围。读取目标 ABSTRACT、SUMMARY，再根据具体问题进入 AS_RUN、脚本与结果；涉及推断时核对 PROJECT 中的实验设计和独立重复。

按证据缺口选择当前可用工具或独立 agent，传递问题和最小相关材料。能读文件时按需取证；遇到实际访问限制时提供必要摘录并说明未核验范围。宿主名称不能证明用了不同模型，异模型审核不是默认必需条件。

审核者只读被审代码和结果。独立执行环境是否有只读隔离取决于宿主实际配置，不能把角色 prompt 当权限保证；报告交主会话落入该单元的 `review/check_<reviewer>_<YYYYMMDD>_<序号>/review.md`，归档任务先恢复再新增报告。

每项判断引用真实文件和数字，区分已证实问题与待确认疑点；无法验证的事项明确列为限制。无问题的审核也是有效结果，不能因零 findings、输出短或包含某个关键词就判调用失败。

报告包含被审对象、核查范围、重要发现、未核验项和总体判断。优先影响科学解释与决策的问题，避免对小改动要求穷举式复算。复审优先检查原问题，新发现若实质影响结论也应报告。结果可为通过、有保留或未通过，不能以格式整改代替科学判断。
