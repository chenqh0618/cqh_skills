# 分析侧

主线分析在 `analysis/` 创建 A 单元。用户指定为主线即可，计划文件不是前置条件。

开始或继续分析时读取项目根 `.project/WORKFLOW.md`，它是分析与探索的共同规则来源。
需要软件时先读 [运行环境与参考代码库](../.project/environments/USAGE.md)，获取实际环境、调用命令与验证范围。
背景、数据和实验设计按需读 `mgmt/PROJECT.md`、`mgmt/RESOURCES.md`；用户指定方案时读取相应方案。
接续已有任务先读其 `ABSTRACT.md`，再读与当前工作相关的结论、运行记录或代码。
归档、恢复与空间清理见 `.project/ARCHIVE.md`。
