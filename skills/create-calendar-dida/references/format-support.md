# 正文格式支持与测试记录

本记录用于选择滴答日程正文的兼容写法。证据截至 **2026-10-12**；客户端版本与平台未记录，结论限定为本次用户的实际客户端，不推广到全部版本。

## 格式选择

| 内容 | 推荐写法 | 证据与限制 |
| --- | --- | --- |
| 简短正文 | 普通段落、换行，必要时不写正文 | 本次创建及回读确认正文保存；保存不等于逐项验证排版 |
| 标题、粗体、斜体、删除线、列表、复选框、引用、分隔线 | 常规 Markdown 或客户端编辑工具 | 官方格式说明列明支持；本次没有逐项取得用户确认 |
| 代码块 | 围栏代码块；表格文字替代可用 `text` | 官方列明支持；等宽文本已写入测试任务，客户端实际对齐未单独确认 |
| 行内代码 | 必要时使用短标识；普通文字也是可读替代 | 本次写入并回读过行内代码语法，未单独确认客户端渲染 |
| Markdown 管道表格 | 默认转换为逐项列表 | 用户两次确认显示为源码；原测试语法没有发现明显错误，不将换图床当作解决方法 |
| 图片外链 | Markdown 图片语法，必要时附“打开原图”链接 | 用户已确认部分 URL 可正常内嵌，见下节 |
| 普通链接与关联日程 | `[明确的名称](真实URL)` | 官方支持链接和任务间跳转；本次实际取得任务 URL，未对客户端跳转逐项验收 |
| HTML、数据 URI 或本地文件路径嵌图 | 不作为默认解决方案 | 本次未验证；本地路径不能作为其他设备可访问的图片地址 |

官方说明可能与国内客户端或具体版本存在差异。“官方列明支持”“接口保存成功”“用户确认显示正常”是三种证据，分别表述。

## 表格的替代方式

以正文可读性为先，默认把每一行改成一个条目，例如：

```markdown
- **蓝莓补给**：数量 24；状态就绪。
- **纸飞机**：数量 7；状态排队。
```

用户需要简单行列布局时，可使用等宽代码块，但要说明这仍是文字排版，不能按单元格编辑；中文与西文字体的宽度差异可能影响对齐，窄屏也可能换行。

需要稳定的表格外观时，可用绘表工具生成 PNG，按实际展示尺寸设置清晰字体，再通过可用的附件能力上传。当前连接器未提供该能力时，提供图片文件供用户在客户端上传，并明确尚未上传；不要把本地生成成功说成已经插入日程。

需要编辑单元格或维护复杂数据时，将表格保留在用户指定的表格文件或已有文档中，日程正文放真实链接。不要为一次普通日程自动创建外部文档或公开图床。

## 图片 URL 的实测范围

| URL | 用户客户端结果 |
| --- | --- |
| `https://www.baidu.com/img/flexible/logo/pc/result.png` | 显示正常 |
| `https://httpbin.org/image/png` | 此前无法显示 |
| `http://httpbin.org/image/png` | 用户改用 HTTP 后确认正常 |

这是三个具体 URL 在该客户端及网络下的表现。不能据此断定大陆无法访问 httpbin，也不能断定客户端普遍不支持 HTTPS；TLS、代理、缓存或图片加载逻辑的具体原因均未确定。执行环境曾遇到的网络错误也不能替代用户客户端的结果。

- 优先使用用户提供或已确认可用的 HTTPS 图片直链；用户明确提供并验证过的 HTTP 地址可以使用。
- 某图片加载失败时，先用同地址的“打开原图”链接区分资源访问和内嵌渲染问题；不批量替换 URL 协议。
- 不因为上述网址曾通过测试，就自动把示例图片加入正式日程。实际图片应与日程内容相关。
- 先查看当前连接器的实际能力。截至本次核查，滴答连接器没有附件上传工具，任务创建／更新参数也没有附件字段。若能力以后增加，再按实际接口处理本地图片。
- 客户端本身支持本地图片：任务菜单中的“附件／上传附件”；桌面端也可在任务详情中粘贴图片。
