# 语义检查场景（用于后续真实论文评估；本次未跑真实论文）

1. **八幅主图的机制论文**：应收束为3–5个研究节点，可整合主图与补图。遗漏会改变主结论的反向结果即失败；没有覆盖全部子图本身不是失败。
2. **单细胞图谱、没有机制干预**：应识别资源与发现主线，不强造机制闭环，也不把表达/组成变化写成已经证明的细胞命运变化。
3. **其他器官或发育论文**：可借鉴问题拆分、采样或证据设计；不得将异组织结论直接写成CS肺修复机制。没有可靠迁移价值时允许少写或不写建议。
4. **方法学论文**：聚焦它解决的具体困难、核心检验及适用范围；课题启发应说明用户数据是否满足条件，不以工具名称清单替代分析逻辑。
5. **现有数据与实验资源**：不能把另一个年龄队列拼接到2/4/6/8月暴露队列，不能把曾讨论的谱系追踪等当作已具备条件。
6. **原图或关键补充材料不可用**：应标明有限解读及缺口；不能只看图注就声称图像核验通过，也不能靠合理猜测补写实验。
7. **只有一个有价值的启发**：应写深这一条，不凑齐科学问题、实验设计、分析方法等分类。明确其论文触发点、迁移做法及价值/边界。
8. **写法退化为详细版**：逐图逐子图完整展开、八项检查反复出现、堆积样本/软件细节、末尾再重复全文摘要，均不符合本技能，即便事实无误。
