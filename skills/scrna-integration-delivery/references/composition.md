# celltype 与 cluster 组成

用于描述性样本组成交付及必要的计数／比例汇总。默认分别统计逐细胞 celltype 与主分辨率 cluster；其他 resolution 独立记录。新增条件比较须属于用户任务，并按独立实验单位另行设计模型。

## 分母与样本

默认使用当前分析对象、当前流程内的全部保留细胞，有 projected 时包含它们并记录范围：

```text
n_s,k = 样本 s 中类别 k 的细胞数
N_s = 样本 s 在当前对象、当前流程内的全部保留细胞数
p_s,k = n_s,k / N_s
group_mean_g,k = 组 g 中所有有效样本 p_s,k 的等权算术平均
```

每个细胞在每套分类中只计入一个类别。保留正式的混合／未定项；celltype 空值根据已有注释状态建立明确的展示类别，原字段和映射保留。混合标签不能拆成两份计数，非互斥的多标签 state 另做发生率，不能归一化成 100% 堆叠组成。

有效样本中各类别数量之和为 `N_s`，比例之和为 1。**组平均按样本比例等权，不按细胞数加权**。例如两个样本分别为 10/100 和 45/50，则组均值为 50%；合并细胞的 55/150 ≈ 36.7% 是另一口径。

先按实验设计合并同一样本的技术捕获，核对细胞无重复；保存 sample、donor/animal、library 对应关系。重复取样的 sample 均值仍为描述性样本均值，不能当作多个独立供体用于推断。

以外部样本清单和输入记录识别缺失，不能只从保留细胞反推样本清单。补齐有效样本×类别组合；类别全集为当前分析范围内实际保留的互斥类别及项目明确的展示类别。

| 情形 | 数量与比例 | 组均值处理 |
| --- | --- | --- |
| 有效样本中该类别不存在 | n=0、p=0 | 保留，参与平均 |
| 已观测样本在当前对象中无保留细胞 | N=0、各类 n=0、p=NA | 排除并报告，无保留细胞不等于各类都是 0% |
| 样本输入或整份观测缺失 | n、N、p 均为 NA | 排除并报告缺失原因 |
| 整组无有效样本 | 有效样本数为 0、组均值 NA | 保留组位置及不可计算标识 |
| 不同分析对象成员重叠 | 各对象内独立计数 | 不跨对象相加构造总体组成 |

各类别组均值使用该组相同的有效样本集合，真实零须包含在平均中。组均值表记录总样本数、有效样本数和排除数。不同流程若保留成员不同，分别记录分母和交集；不能将比例差异全部归因于注释变化。使用全数据集、父谱系等其他分母时另命名结果并记录分母集合，当前子集比例不自动代表组织绝对丰度。

## 每个层级的五类图

celltype 和主分辨率 cluster 各保存下列图形、数值底表及样本／类别顺序。局部请求只绘指定类型。PDF/300 dpi PNG 配套导出，最终尺寸正文／坐标以约 11–12 pt 为起点，过多类别分页，不隐去稀有或未定群。

| 文件 stem 示例 | 内容与标注 |
| --- | --- |
| `proportion.by_sample` | 按类别分面，x 为实验组，y 为样本比例，每点一个有效样本；固定抖动 seed，底表可定位样本 ID，图注报告缺失／无效样本 |
| `heatmap.counts` | 行为类别、列为样本，按 group 排列并添加条件／时间等实际列注释；格内标整数 n，默认颜色为原始 n，列注释显示 N；缺失格标 NA |
| `heatmap.proportions` | 同数量热图顺序；颜色范围 0–100%，格内标百分比，默认一位小数；极小正值可标 `<0.1%`，区别于真实 0；底表保留未舍入值 |
| `stacked_bar.by_sample` | 每柱一个样本、填充为类别，y 为 0–100%；按实验组分面或分块，柱上标 N；零分母／缺失样本保留位置与状态标记 |
| `stacked_bar.group_mean` | 每柱一个组，堆叠样本等权平均比例，y 为 0–100%；标有效样本数，图注交代总样本／排除数和平均口径 |

同层级各图的类别颜色与样本顺序固定。cluster 热图按正式 cluster celltype 映射分行组；celltype 图直接显示类别。组和时间顺序按实验设计或既定配置，不按结果大小临时重排。热图两种数值使用各自明确的图例；如对数量颜色作变换，保留原始数量标注并注明变换。

保留未定类别及零／缺失位置，不把无效样本画成正常的 0% 组成；整组 NA 也不能伪造堆叠柱。堆叠图展示总体构成，逐样本散点和热图用于看到样本差异。

## 底表与核验

样本底表至少包含分支、层级、resolution（如适用）、sample、donor、group、类别、`n_cells`、`denominator_n`、`proportion`、分母定义、有效性及缺失原因；组均值表包含类别均值及样本纳入数量。保存展示顺序和调色板，不用只含舍入百分比的表作为权威结果。

从细胞标签回算各样本计数，核对计数守恒、比例和为 1、真实零与 NA 的处理。以样本比例重算组均值，确认各类别使用同一有效样本集合且合计为 1；全无效组保持 NA。检查技术捕获及重叠对象未重复计数，图上数字和柱高与底表一致，文字和分面在最终尺寸可读。数量反映实际捕获与处理后的细胞，不能直接当作组织绝对丰度。
