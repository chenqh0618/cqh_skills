# 在实验出现的当下解释证据

按论文实际使用的方法选读本文件。它提供教学组织方式，不是论文事实或可直接套用的图注。核实该研究的测量层次、关键对照与分析单位后再写；不补猜数值、缩写全称或操作参数。

## 用四句话教会读者理解一个实验

1. **要区分什么解释？** 先承接上一节点的未知，例如细胞比例变化来自状态改变、数量变化，还是取样差异。
2. **实际测什么？** 从测量对象、读出与图上呈现方式解释方法；不要只报技术名。
3. **为什么需要对照？** 点明哪两个对象可比较，以及关键对照排除了哪一种混淆。缺失重要对照时说明仍有哪些解释。
4. **能走到哪一步？** 紧贴观察给有范围的结论，再引出仍需另一种证据回答的问题。

将四句话融入连续叙事。只在需要额外先修知识时插一个概念讲解框，不按这四项重复小标题。

## 常见方法怎样讲

以下是解释方向，具体读出与证据范围以原论文为准。

| 论文中的方法 | 先解释的测量与读图问题 | 关键对照与证据边界 |
| --- | --- | --- |
| RNA测序、单细胞RNA测序 | 量到的是RNA丰度；单细胞数据区分细胞间的表达差异。解释颜色表示基因表达、样本组别还是计算分数。 | 核查独立样本、处理组与取样；RNA变化不能单独证明蛋白活性或功能变化。 |
| UMAP、聚类与热图 | UMAP是把表达特征压缩成便于观察的二维位置；轴通常不是时间或真实组织坐标。热图先解释行、列及色标。 | 图上相邻与表达相似有关，不能仅凭位置推断真实接触、来源或分化方向。 |
| 拟时序、RNA velocity | 解释算法利用哪类测量来推断细胞状态顺序或变化趋势。不要把推定顺序当作逐个细胞的录像。 | 核查时间点、起点假设与来源验证；计算趋势可以提出谱系假说，不能单独证明A成为B。 |
| 染色与显微成像 | 解释信号对应什么结构或分子，颜色、比例尺与量化区域；一个视野不必然是一份独立样本。 | 按原文说明用于检查信号特异性或组间差异的对照；表达或空间接近不能单独证明作用机制。 |
| 谱系追踪 | 解释标记的是起始细胞及其后代，从而检验来源；区分永久来源标记与当下表达标志物。 | 核查起始标记特异性、标记时序、覆盖范围及相关对照；没有被标记不必然证明没有贡献。 |
| 遗传或药理干预 | 解释改变的对象与后续功能读出，区分“改变候选因素”和“直接测量它的作用”。 | 核查相应对照、干预特异性与存活等替代解释；变化可以加强因果证据，直接机制还需相应证据。 |
| 救援实验 | 解释在干预后恢复哪一因素，哪个读出回到什么程度。 | 区分完全与部分恢复；一个指标恢复不等于整个疾病或系统完全恢复。 |

## 把统计信息放在读者正在比较的位置

- 先问一个点、柱或线代表什么，再查`n`代表独立动物、供体、样本、细胞还是视野。一个样本内的多个细胞属于嵌套测量，不能自动算成多份独立生物学重复。
- 解释论文实际报告的误差线；标准差、标准误和置信区间不同，不凭图形样式判断。未注明时直说未注明。
- 同时描述方向、幅度与不确定性。统计显著不自动等于生物学意义大；不显著不证明效果恰为零。
- 核查比例的分母。某群细胞比例上升可能来自它增多，也可能来自其他群体减少；没有绝对计数或相应读出时收窄判断。

## 可迁移的概念框写法

以下框中的内容仅展示说明层次，使用时根据待解读论文改写。

**先懂一个概念｜对照**

对照提供判断变化的参照。在这个实验中，要说明研究组与对照组实际相差什么，以及比较它们能帮助排除哪种解释。如果组间还有其他系统差异，结果仍可能包含这些因素的影响。

**先懂一个概念｜标志物与细胞身份**

标志物是识别细胞的线索，可能随状态改变。解释这篇论文为什么选择它，以及还用什么证据确认细胞身份；仅见某基因表达，不能直接宣布发现新细胞类型或确定其来源。

把决定性限制留在正文。技术背景与额外验证可折叠，不能把改变结论的负结果藏起来。
