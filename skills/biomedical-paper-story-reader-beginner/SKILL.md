# 生物医学论文故事解读 · 初学者版

## 目标与阅读契约

让读者既能复述论文的科学故事，也能说清关键证据为什么支持某个判断、还不能证明什么。面向初学者意味着降低先修知识门槛，不等于降低科学严谨性、删掉决定性证据，或认定用户本人没有专业背景。

默认中文、自然连贯的叙事；把必要的深度放在读者需要它的位置。用户明确指定其他语言、长度或仅一个节选时服从其范围。完整论文解读默认交付实际 `.html` 文件，不仅给聊天正文。

作为独立的初学者版本运行；保留 `biomedical-paper-story-reader` 和 `biomedical-paper-mainline-reader` 的名称、内容与用途，不把二者当作同一技能，也不覆盖它们。

使用 `assets/report_template.html` 制作独立报告；需要把专业表述转为教学叙事时读 `references/teaching-example.md`，需要解释实验的测量原理、对照或统计单位时读 `references/experiment-guide.md`。参考示例只用于写法，不是待解读论文的证据。

## 1. 先确认材料，再重建科学问题

1. 确认标题、作者、年份、DOI/稳定网址及版本。读取可获得的全文、图注、相关方法和关键补充材料，不凭摘要编全篇故事。
2. 查看关键原图本身并核对图注；PDF提取文字不能代替读图。跟踪每个事实对应的页码、Figure/panel、图注或方法段落。
3. 材料缺失时先说明实际阅读范围。可提供明确标为有限材料的解读；不能捏造图像、数值、样本量或缺失实验。若连核心问题都无法确定，索取论文/链接。
4. 内部列出：已有认识→知识缺口→中心问题→关键子问题→改变认识的证据→未解问题。分清作者实际做的实验与为解释逻辑而重排的叙述顺序，不编造研究者当时的想法。
5. 挑出通常 **3–5个主线节点**，复杂或极短研究可调整。保留关键对照、干预证据、替代解释和会改变结论的负结果；舍弃重复验证与无关支线。若论文只有关联，不强行套“发现→机制→治疗”的完整闭环。

## 2. 开场只补“现在就用得上”的背景

用2–4段回答：研究的是哪个生物系统？它通常怎样工作？哪里有重要未知？回答这个问题为什么有意义？

- 根据这篇论文提供理解问题所需的细胞、组织、分子和疾病背景；从较熟悉的层次逐步走向陌生层次。
- 初次出现的术语给出简短中文解释；缩写首次出现给中文名和英文全称（确实可核实时），以后用一致称呼。不要用另一个未解释术语解释第一个术语。
- 用“知道它是什么、在这里做什么、为什么现在提它”替代百科全书式定义。后面才用到的知识，留到对应节点。
- 背景事实与论文新结果明确分开。需要外部背景来源时用可核实的权威资料或原始研究，勿把它们算作本论文证据。
- 可用少量类比帮助理解，紧接一句说明类比在哪失效。避免把细胞说成有意图、把通路说成单一开关或把复杂疾病说成一个零件坏了。
- 不安排长篇先修课程、开头缩写墙或默认测验。无需读者先回答知识水平问卷；已知阅读需求就直接开始。
- 遇到会阻碍下一段理解的概念，使用模板中的 `<aside class="concept">` 讲解框，简述“它是什么、在本文中做什么、不能说明什么”。先讲再用；每个节点通常零到两个框，短术语直接在句内解释。把延伸背景放入折叠区，不让概念框打断主线。

## 3. 用一条递进问题串起关键节点

先给3–5句“故事地图”，各句写科学问题或认识的变化，不仅列方法名。每个节点用内容相关的小标题和连续段落自然涵盖：

**上一问为何留下缺口 → 这次怎么问 → 实际看到了什么 → 可以怎样解释/还有哪些限制 → 下一步为什么必要。**

不要把正文拆成固定的七八栏表格，也不要重复逐panel复述。节点之间明确过渡：上一结果解决了什么，它为什么仍留下下一问。

### 在实验出现的当下教会读者

先说实验测量的对象和读出，再介绍必要的方法名。例如解释RNA测序测的是RNA丰度，不是直接测蛋白活性；具体解释应与该论文实际方法一致。

说明选这个方法能区分哪些解释，关键对照控制了什么因素、缺少它会出现什么误读。讲测量原理和证据逻辑，不堆步骤、剂量、仪器参数或操作配方。遇到可能被滥用于生物危害的研究，仅提供非操作性的科学意义、证据局限与安全背景。

### 对每张选图给出具体的“看图路线”

默认嵌入3–6个关键Figure/panel，必要时加少量关键补图；数量服务于理解。

1. 先指认图型及阅读方向：横纵轴是什么、单位是什么；热图/图像/降维图则解释其空间、色标或坐标含义，不硬套物理轴。
2. 指明分组、颜色、符号及最重要的比较；不同组颜色不能凭印象猜。告诉读者先看哪里、比较什么、随后看哪个变化。
3. 解释一个点/一条线/一个柱代表什么；交代n是独立动物、患者、供体、样本、视野还是细胞。未报告或不能确定就明确说，不填猜测值。
4. 简释误差线、显著性和效应大小：只解释原文报告的统计量；不显著不等于证明无效，显著不等于重要。方向、幅度与不确定性共同决定解释。
5. 紧贴图面描述直接观察，再说明解释。若裁panel，保留图号、panel标签、轴、色标、对照及裁剪说明。

短的“读图提示”可以重复出现；只在真正的转折处放“证据锚点”卡，避免每节都复制模板。

## 4. 让证据边界本身也能被初学者理解

在影响结论之处自然解释下面的区别，而非结尾堆一整页免责声明：

- **观察 / 作者解释 / 本报告推断**：用“图中显示…”“作者据此提出…”“一种可能解释是…”区分。每项推断交代依据与尚缺的验证。
- **相关 / 因果 / 直接机制**：共同变化不证明互相导致；差异表达、富集、共定位和配体-受体推断提供线索。干预可加强因果证据，仍需考虑脱靶、间接作用和模型限制；救援只恢复部分就如实说部分。
- **标志物 / 细胞身份 / 来源谱系**：标志物是识别线索，可能随状态变化，不是永久身份证；表达相似、聚类和计算轨迹不证明细胞A变成B。谱系追踪才可能检验来源，还要看标记特异性、时序与覆盖范围。
- **RNA / 蛋白 / 功能**：量到某一层，不等于证明其他层变化；在论文关键转折处解释为何还需要功能读出。
- **细胞数 / 独立重复**：同一供体的一千个细胞不能当作一千位独立供体；把同一样本内的测量当成独立重复会高估证据，称为伪重复。核查分析是否处理嵌套结构，不因细胞多就判定可靠。
- **模型内结果 / 人类疾病与治疗**：培养细胞、动物、患者相关性各有范围；组织表达不等于临床疗效，病理改善不等于疾病全部逆转。

关键负结果、模型间不一致、未排除的主要替代解释必须保留，不为流畅而剪掉。不给没有干预的研究编“机制转折”。

## 5. 收束：少而清楚地记住什么

先用一段话复述问题推进和最扎实的结论，再给三个短点：已建立的认识、还不能下的判断、最值得继续问的问题。可附一两句“如果只记住一件事…”，不再翻译摘要。

若用户确有已知研究课题且相关，可增加少量可迁移的科学问题或分析思路；不要自动把所有论文套到肺损伤或假定用户在做某实验。个性化建议与论文结论分开。

正文默认约3,000–5,000中文字，可为必要解释调整；用户要求更短时减少节点和旁支，不牺牲关键边界。术语小词典、技术深读和补充验证可用HTML的 `details/summary` 折叠；首次理解主线所需解释仍留正文。词典只收本报告用到的词。

## 6. HTML交付与可追溯性

- 使用标题、论文信息/原文链接、一句话故事、恰好够用的背景、故事地图、关键节点、收束、可选术语/深读、阅读范围与参考来源的结构。
- 沿用图文交错、适合长文阅读的单栏；正文适中宽度、手机可读，少量重点色与卡片，不做大证据矩阵。
- 原图来自核实的论文/PDF/授权来源；不得用生成式图像或重新画的数据图冒充原图。自制概念示意若必要，清楚标为本报告示意、非实测结果。
- 图注注明作者/论文、年份、Figure/panel、原始来源链接、裁剪情况及可核实的许可/版权信息；不臆造许可。无法合法或可靠获取原图时给原图链接和文字导读，并明确没有嵌入。
- 默认将可合法嵌入的图像编码为data URI，CSS内联；不依赖外部脚本、字体或联网资源。保留可点击出处和文中图号/页码锚点，外链需联网不妨碍正文离线阅读。
- 给图像有意义的alt文本，解释颜色时兼用组名；保留原图分辨率，必要时允许放大。不要让折叠内容藏住决定性局限。
- 交付前生成实际HTML，在可用浏览器/渲染器查看桌面和窄屏、图像清晰度、溢出、锚点与折叠内容；能离线检查时禁网确认。未做的检查如实说明，不宣称通过。
- 删除占位词和空章节；检查每个事实的出处、原图与图注对应关系、首次术语解释、n与统计单位及关键负结果。提供真实可访问的文件链接或附件，不以代码块代替文件。

## 最后自检

读者能否回答：为什么问这个问题？关键实验到底测了什么？哪两个对象在比较？对照排除了什么？图里直接看到什么？下一问为什么出现？结论在哪个范围内成立？

若答案依赖未解释缩写或隐藏的生物学知识，补一句解释；若答案依赖论文没有提供的证据，收窄结论。
