# 发布前检查清单

## 内容与来源

- [ ] 确认论文身份、版本和材料获取范围；出版状态核验有无完成如实标明。
- [ ] 背景区分前人工作与本文新增发现；背景事实有来源。
- [ ] 科学问题、模型/人群、设计和研究整体逻辑清楚。
- [ ] 主图数量和图号与原文一致；所有子图都进入覆盖清单。
- [ ] 所有主图已看图，或逐图明确标记仅依据文字/图注。
- [ ] 关键主张回查对应方法和补充证据；缺失材料可见。
- [ ] 子图中的 n、比较、测量单位、误差条和检验尽量核实，未知值没有补写。
- [ ] 生物学重复/技术重复、样本数/细胞数没有混淆。
- [ ] 直接观察、作者解释和报告评估明确分开。
- [ ] 未把计算关系、示意图、关联或不显著结果写成更强证明。
- [ ] 结论涉及必要性/充分性/直接机制时，对照和限定范围相匹配。
- [ ] 不一致证据、关键替代解释和负结果没有因叙事被省略。
- [ ] 图与图的承接真实；并行图、技术图和总结图没有被强行串成机制。
- [ ] 贡献和局限按研究类型判断，不以期刊声望代替证据。
- [ ] 后续实验被清楚标记为建议，并对应具体证据缺口。
- [ ] 关键断言有正确图/子图/页/方法定位，外部研究与本文证据不混写。

## HTML 与交付

- [ ] 实际生成 HTML 文件，不是只给出代码块。
- [ ] 单文件正文离线可读；未嵌入远端字体/JS/追踪代码。
- [ ] 原图、公式和流程正确显示，不依赖未加载的 CDN。
- [ ] 引用跳转与目录锚点有效；没有重复 ID 或失效内部链接。
- [ ] 无残留平台私有引用标记；完整报告没有模板占位符。
- [ ] 桌面与窄屏布局可读，宽表不导致整个页面横向溢出。
- [ ] 对“看过图”“完成统计复核”“端到端测试”的表述与实际工作一致。
- [ ] 报告状态为 template/partial/complete 中准确的一种。
- [ ] 下载链接指向确实存在的文件；缺失材料限制紧邻链接说明。

## 硬性失败条件

虚构图号、实验、样本量或来源；未见图却说“图中可见”；把演示写成真实论文；代码不能生成 HTML；完整报告主图漏读；引用对应错误；机制语气明显超过证据且未给限定。出现这些问题必须修订后交付，或明确降级为部分解读。

## 验证边界

结构检查通过不代表科学解释正确。语义测试需要模型运行后逐项评估；没有目标论文与真实模型输出时，只能声称创建了测试用例，不能声称技能已通过真实论文端到端验证。
