OVERVIEW / 01

研究背景：已知什么，真正缺什么

先把论文放回它要解决的问题中

背景部分不是扩写摘要：应区分研究领域已有认识、仍有分歧或缺少证据的环节，以及这个缺口为什么重要。

真实报告在此说明疾病或生物过程背景，并将前人工作与本文新增证据分开。背景只保留理解后续实验所必需的内容，每个具体事实附原始文献或本论文引言定位。

随后指出知识缺口属于哪一类：缺少资源、现象尚未被可靠描述、存在竞争解释、缺少功能或因果证据，还是尚未建立临床可用性。

OVERVIEW / 02

研究目的与设计：问题要如何被回答

将总体目的拆成若干可回答的科学问题；验证性研究明确假设，探索性图谱明确资源与发现目标。不要在结果已知后虚构作者预先提出的假设。

需要交代真实报告填写内容
研究对象物种 / 组织 / 人群 / 队列 / 模型，及其选择理由。
核心问题作者希望回答什么，当前证据为什么不足。
研究设计分组、干预、时间点、测量、对照及验证路径。
数据来源本研究新测、公开数据再分析、独立验证三者分开。
重复与统计单位供者、动物、独立培养、细胞或视野分别是多少，未知就标记。

MAIN FIGURE / 01

Figure 1｜界定研究对象与核心现象（结构示例）

示例作用：建立研究系统和直接观察，为后续问题提供依据。实际内容以论文为准。

演示条目

① 背景与承接

从引言的知识缺口切入：此前哪些认识不足，为什么需要对研究对象进行这一轮采样、测量或分析？不要把作者在本图才得到的结论当作已知背景。

② 目的与假设

本图是在建立资源、证明一个现象存在，还是比较不同状态？将图标题变成可回答的问题；探索性图不强行预设机制假说。

③ 实验或分析设计

交代对象、分组、时间点、对照、读出、重复与分析策略。解释为何该实验能回答问题，而不只是列出测序、染色或算法名称。

真实报告必须注明 n 的具体含义；没有报告的数值使用“原文未报告”，未获取的方法使用“材料未获取”。

④ 子图证据

子图方法/测量关键比较直接观察
a设计或流程示意（示例）填写实际采样及分组。记录流程，不编写生物学结果。
b / c数据展示与主要比较（示例）填写组间或条件间的真实比较。先读坐标和单位，再描述来源可核对的方向和数值。
d正交测量或定量验证（示例）核对其是否与主分析对应，是否真正独立。区分代表性图像与群体定量。
子图可以支持不能据此推出证据定位
a说明研究如何组织。流程示意本身不证明任何生物学效应。实际使用时填写：图号、子图、PDF 页与 Methods 小节。
b / c仅给出由测量直接支持的描述或关联。不能仅凭关联判断来源、机制或因果。实际使用时填写：图号、子图、PDF 页与 Methods 小节。
d按设计说明是否增加可重复性或证据一致性。不能因使用第二种技术就自动称独立生物学复制。实际使用时填写：图号、子图、PDF 页与 Methods 小节。

⑤ 结果怎样解读

在真实报告中，解释图的坐标、颜色、单位、误差和比较基准，再叙述最关键的结果。确切数值来自原文，图中趋势与目测估计明确区分。

代表性图像、统计汇总和计算输出各自承担什么证据角色？子图之间是否互相支持，有没有应保留的不一致结果？

⑥ 证据如何支持结论

证据 → 推论 → 范围

在【对象与条件】下观察到【可核对结果】，因此支持【最小结论】。要推进到【更强主张】，仍须检验【关键前提或替代解释】。

分别标出作者如何解释结果，以及本报告认为证据实际上能够支持到哪一层。

⑦ 边界与未解决问题

优先指出对当前主张影响最大的缺口，例如实际统计单位不清、相对量不能说明绝对变化、缺少区分竞争解释的对照。是否存在这些问题必须回查原文，不能直接从模板套用。

⑧ 本图小结与下一图

本图结论与后续问题

真实填写：本图已经支持什么；仍无法回答什么；下一幅图是否针对这个缺口设计实验。若下一图属于并行验证，直接说明，不编造递进关系。

MAIN FIGURE / 02

Figure 2｜追问解释或补充验证（结构示例）

示例作用：承接尚未解决的问题，或者提供并行、独立、跨模型证据；不预设图 2 必须是机制图。

演示条目

① 背景与承接

明确图 1 给了哪条事实，但没有排除哪些解释。若图 2 实际在验证技术性能或引入另一队列，就按真实关系叙述。

② 目的与假设

定义本图所要检验的候选关系、功能贡献或外部可重复性。说明不同可能结果将如何支持或削弱这些解释。

③ 实验或分析设计

写清干预或验证对象、阳性/阴性对照、匹配条件、时间与读出。只解释论文实际进行的实验；不能为了形成完整证据链而补写救援或谱系追踪。

④ 子图证据

子图方法/测量关键比较直接观察
a候选解释或验证入口（示例）按真实研究填写。列出直接测量或计算推断，两者明确区分。
b干预、正交测量或独立验证（示例）核对对照和研究单位。如实保留支持与不支持的结果。
c进一步验证或总结（示例）判断是否新增实验及独立证据。模型示意与实际实验结果分开。
子图可以支持不能据此推出证据定位
a说明候选机制为何值得检验。候选关系不等于已验证机制。实际使用时填写：图号、子图、PDF 页与 Methods 小节。
b证据增加到哪一层由实际设计决定。干预效应不自动等于唯一、直接机制。实际使用时填写：图号、子图、PDF 页与 Methods 小节。
c说明该子图补足的具体环节。总结模型不是新的实验证据。实际使用时填写：图号、子图、PDF 页与 Methods 小节。

⑤ 结果怎样解读

将本图结果与前图已有结论放在一起：它是补强、限制、解释，还是提出了新的矛盾？不能只摘取顺着主线的证据。

⑥ 证据如何支持结论

每个机制箭头分别寻找对应证据；对于图谱或方法研究，分别评价资源可靠性、算法性能与生物学解释，不强制要求不存在的因果闭环。

⑦ 边界与未解决问题

本图是否确实排除了竞争解释？跨物种、体内外或临床外推是否越过了研究边界？使用具体图号和方法说明判断依据。

⑧ 本图小结与下一图

本图增加了什么

真实填写：相对图 1，新增加的证据是什么、哪些问题仍然开放。实际论文还有后续主图时，继续沿用同一结构，不在图 2 提前结束。

SYNTHESIS

综合回答：科学问题与证据逐一对应

科学问题最稳妥的答案关键证据剩余缺口
按论文目的填写问题 1用有条件、有限定范围的结论回答。填写真实 Figure / 子图 / 方法定位。哪些更强主张尚不能成立？
按论文目的填写问题 2区分直接结果与作者的解释。标明相互支持或不一致的证据。关键替代解释是否得到区分？

工作模型需要逐条标注哪些关系有直接支持，哪些来自计算推断，哪些仅是未检验假设。图谱的资源贡献、方法性能和生物学机制分别评价。

SYNTHESIS

贡献、局限与最有区分力的下一步

主要贡献应说明论文增加了什么资源、可靠现象、方法能力或机制认识，而不是用期刊声望替代证据评价。

最重要的未解决问题应对应能够改变核心解释的缺口。不要重复泛泛的“需要更多研究”，也不要因为缺少不属于其研究目标的实验而否定整个工作。

证据缺口需要区分的解释后续验证的判别价值
填写具体尚缺的一环列出至少两个仍可能成立的解释。说明不同结果各支持什么；明确此项是建议而非论文已做。
一句话带走

在【研究对象与条件】下，论文通过【关键证据】支持【核心结论】；但【更强解释或外推】仍需要【对应证据】。
