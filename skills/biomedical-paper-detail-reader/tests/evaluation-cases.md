# 语义评估用例（已编写，尚未在真实论文上逐项运行）

每项只评估要求是否满足，不累计成论文质量分。可用人工审阅或独立模型审阅生成的完整报告；保留输入、输出和审阅记录。

| 场景 | 预期行为 | 不应出现 |
|---|---|---|
| 只有摘要，全文不可获取 | 标记部分解读；不虚构主图和实验；解释材料缺口 | 自动生成 Figure 1–6 的详细实验 |
| 正文可读、主图图片不可读 | 明示图像未核验，只引用可核对文字；不称完整逐图视觉核验 | “从散点分布可以看到” |
| Fig. 1 包含 a–h，部分子图为流程/质控 | 覆盖全部子图，可分组；说明流程图不提供生物学结果 | 只讲 a–c 或把流程图当独立验证 |
| 图谱研究没有功能干预 | 评价采样、资源、注释、复现和候选解释的边界 | 因无救援实验直接否定图谱价值 |
| 六名供者共十万细胞 | 区分供者与细胞；核对统计单位 | 将十万细胞写成十万个生物学重复 |
| 伪时间或 RNA velocity 指向一种转换 | 标记模型推断，解释假设与来源证据缺口 | 称已证明祖细胞—后代关系 |
| 基因抑制伴随表型变化且存在毒性风险 | 讨论效率、特异性与毒性对解释的影响 | 单靠表型下降认定直接机制 |
| 含救援和结合实验但缺少功能位点验证 | 逐项说明证据新增了什么和不能排除什么 | 救援自动等于机制完全闭环 |
| 两图属于并行验证或跨模型复现 | 写成并行/独立验证，并核对是否真正独立 | 强制写为上一图提出下一图假设 |
| 主模型与某子图结果不一致 | 保留并分析不一致，不擅自抹除 | 只引用支持主模型的结果 |
| 临床观察队列报告相关性 | 按设计解释混杂和外推，不给个体治疗建议 | 直接写成随机干预的因果结论 |
| HTML 含中文、宽表、公式、流程和引用 | 单文件正文离线可读、定位准确、无失效锚点 | 裸 Mermaid/LaTeX 或只有远端 CDN 渲染 |

## 一个非真实研究的措辞测试

输入：“在某模型里，处理组的标记阳性细胞比例升高；研究未报告绝对数量，也没有追踪来源。”

合格表述：“支持所测样本中该标记阳性群体相对比例升高；尚不能区分绝对扩增、其他群体减少、状态转换或取样变化，也不能据此确定细胞来源。”

不合格表述：“该处理促进此类干细胞增殖并分化产生后代。”

以上只是逻辑测试，不引用或影射任何真实论文。
