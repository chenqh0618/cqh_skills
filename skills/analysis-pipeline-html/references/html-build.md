# HTML 构建与检查

脚本处理图片携带和结构检查，不判断科学结论是否正确，也不自动推断步骤。先按 SKILL.md 核实内容，再使用模板。

## 使用模板

复制 `assets/report_template.html` 到目标单元的工作目录，填入以下占位内容：

| 占位符 | 内容 |
| --- | --- |
| `{{TITLE}}`、`{{UNIT}}`、`{{MODE}}`、`{{DATE}}` | 页面标题、目标单元、明确的模式、整理日期；普通文本须 HTML 转义。 |
| `{{INTRO}}` | 问题、数据范围、研究设计及必要的输入概述。 |
| `{{OVERVIEW}}` | 用模板的 flow/branch 样式或内联 SVG 表达实际依赖；复杂关系可分段，不强制线性步骤。 |
| `{{STEPS}}` | 真实分析步骤，复制模板注释中的结构示例并填入内容。 |
| `{{CONCLUSIONS}}` | 当前证据支持的判断及主要边界；必要术语可放在这里的可展开区域。 |

模板自动根据 `.step` 的标题生成导航。各步骤有唯一 ID；`data-origin` 可记录所属上游单元。关键图片使用 `figure > img`，配可见 `figcaption`；点击图片可在内置对话框放大。方法补充使用 `details`，核心结果保持可见。

草稿中的本地图片和来源链接均相对于**草稿文件所在目录**解析。可直接使用项目内相对路径，不把当前工作目录当成链接根目录。标题和正文中的 `&`、`<` 等按 HTML 规则转义。

## 图片与来源

选定图片使用 PNG、JPEG、GIF、WebP 或自包含 SVG。模板使用系统字体、内联 CSS/JS；避免引用 CDN、网络图片、外部字体或 iframe。复杂 SVG 若依赖外部资源，先通过已有绘图工具导出为完整 SVG 或 PNG。

PDF 不能直接作为离线图页嵌入。可使用已有 Poppler 或 PyMuPDF 转换所需页，例如：

```bash
pdftoppm -f 3 -l 3 -singlefile -scale-to 2400 -png \
  '<原图册.pdf>' '<工作目录>/figure_page3'
```

图注写明源 PDF 和页码；检查转换后的坐标、字体及图例。只转换所需页面，保留原图；不为文件体积缩小而使图内文字无法辨认。

## 打包与校验

使用 Python 3.10+；脚本仅依赖标准库。以下 `<skill>` 表示当前技能目录，不是写进报告的路径。

```bash
python3 '<skill>/scripts/html_report.py' pack '<工作目录>/draft.html' \
  --output '<分析单元>/analysis_pipeline.html'

python3 '<skill>/scripts/html_report.py' check '<实际输出路径>'
```

模式 2 的默认输出改为 `analysis_pipeline_full.html`。`pack` 内嵌本地 `img`，给图片保留 `data-source` 来源描述，并把本地证据链接改为相对于成品的位置。打印的 JSON 返回实际输出路径、体积、内嵌数量和检查结果。

同名文件默认追加 `_v02` 等；只有用户明确要求更新该文件、且已满足项目版本保留约定时，才添加 `--replace`。打包失败不写成品，也不改输入。没有证据支持的链接应从正文中改为“缺失/未核实”的文字，不能以忽略错误绕过缺口。

检查覆盖：模板残留、重复 ID、断开的同页锚点、本地来源路径、图片 alt、非内嵌资源及 SVG 内外部依赖。网页来源链接只记录、不发网络请求；脚本不是浏览器或 HTML 安全审计器，无法穷举 JavaScript 的动态网络访问。

## 离线与视觉验收

把**成品 HTML 单独复制**到新的临时目录，不复制项目图像和源表，再运行：

```bash
python3 '<skill>/scripts/html_report.py' check '<临时目录>/report.html' --portable
```

`--portable` 仍要求全部展示资源内嵌；搬离项目后缺失的本地来源链接记为 warning，不当作核心内容丢失。正常原位置检查应没有这些缺失。来源链接的可携带性不等于页面可离线阅读。

有浏览器时离线打开复制件，检查桌面和约 390px 窄屏，以及打印预览：

- 流程图、核心结论和关键图表完整可见；每步的三类说明可读。
- 长标题、表格、参数和路径没有挤坏布局；正文没有横向溢出，宽表可在其容器内滚动。
- 导航、展开/收起、图片放大和关闭正常；键盘可操作。
- 打印时补充内容展开、图片已加载，屏幕按钮和导航不占打印版面。

修正后只复查受影响内容。按项目约定保存必要的构建和验收材料，正式交付默认仅提供 HTML；缺少浏览器或渲染失败时明确未做视觉验收。
